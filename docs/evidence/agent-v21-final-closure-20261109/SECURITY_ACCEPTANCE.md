# 安全验收

- 普通用户的记忆维护改为按用户、租户、项目和嵌入版本过滤。重建仅更新该范围内的向量，保留他人的向量和待同步任务。统计采用同一投影范围，重建异常返回固定提示。
- 原 Linux 取证工具的 24 项合成测试全部通过。执行环境使用只读源码挂载、无网络、无额外能力及工具本身的 Landlock 规则，验证 `/dev/null` 写入拒绝和文件链接边界。Windows 普通 pytest 的平台失败保留在基线日志中。
- 新 Compose 使用独立项目、随机回环端口、新 MySQL 与新持久卷。凭据保存在忽略的 `.env.v21-acceptance` 文件中，浏览器记录仅保留请求方法、路径和状态。
- 跨主机取消、失败接管、存储备份恢复、HTTPS、托管密钥和企业 UAT 尚未完成生产验证。
