# 自动派车 V1

V1 使用可维护的贪心策略，不保证数学最优。引擎只处理已加载的数据，不直接访问数据库。

- 按上午、下午依次处理；
- 大包、小包最低趟次按全天累计；
- 单条需求暂不拆分，可合并多个门店需求；
- 同一辆车在同一配送时段最多执行一趟，上午使用后下午可再次参与；
- 无法形成合法车次的需求返回到 `unassigned_demands`。

车型身份只通过 `vehicle_type.code` 识别：`FOUR_METER`、`BIG_VAN`、`SMALL_VAN`。`min_load` 和 `max_load` 只用于每趟载重校验，可以独立调整，不影响车型身份和优先级。

逻辑趟次按“车辆 + 配送时段”独立编号。同一车辆在同一时段可以生成多趟，上午和下午都从第 1 趟开始。当前每时段车型目标为：四米二 1 趟、大包 1 趟、小包 2 趟；目标不是最大趟数，仍有合法需求时车辆可以继续生成后续趟次。

由于 V1 尚未接入发车和预计返仓时间，同一时段暂不支持车辆返仓后再次出车。后续有时间数据后，可将这一保守限制替换为车次时间不重叠校验。
